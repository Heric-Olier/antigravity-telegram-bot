## Release v0.23.1

### Changes

- **Italian interface** — the bot is now fully available in Italian. ([@Johell1NS](https://github.com/Johell1NS))
- **Agent for scheduled tasks** — a task created with `/task` now remembers the agent selected at that moment, runs under it instead of always using Build, and shows it in the task confirmation and in the task details in `/tasklist`.

### Fixes

- **Clear message instead of a crash on unsupported Node.js** — the bot now refuses to start with a readable error on Node.js releases that lack Node-API v10, where it previously died with a silent segfault inside the database driver; supported versions are 22.14+, 23.6+ and 24+. ([@hcsum](https://github.com/hcsum))
- **Complete logs after a crash** — the last entries written just before the process exits, including the uncaught exception report, now reliably reach the log file.

Full changelog: https://github.com/grinev/opencode-telegram-bot/compare/v0.23.0...v0.23.1
