## Changes
- **Rich Messages** — assistant replies now use Telegram's native Rich Messages, so tables, nested bullet lists, block quotes, headings and syntax-highlighted code arrive as real Telegram blocks instead of plain-text imitations.
- **Consistent feedback from buttons** — every menu button now confirms itself the same way: one confirmation instead of a toast and a message at once, errors and refusals shown on the button instead of posted into the chat, and a single cancel behaviour everywhere.

## Fixes
- **A clear answer when an action fails** — an expired question button, a session name typed after the rename prompt is gone, and a failed model, agent or variant switch now each say what happened, instead of leaving the button spinning, sending the name to the agent as a prompt, or piling a second error on the first.

Full changelog: https://github.com/grinev/opencode-telegram-bot/compare/v0.23.1...v0.24.0
